# Longer fixed-graph scheduling controls

Four independent searches, each with 100 trials of 1,200 native iterations,
retain 914 cycles for the 910-bound graph. None improves the already verified
schedule. This is search evidence, not a proof that the four-cycle gap is
unavoidable. `run.py` reproduces the screen; `regression_tests.log` records the
28 passing research regressions for the promoted builder tools.
